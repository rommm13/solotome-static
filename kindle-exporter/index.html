SoloTome

Kindle Exporter для Send to Kindle / Personal Documents

Расширение работает локально в уже открытой Amazon Content Library. Оно не получает и не передаёт пароль Amazon, cookies или токены на сервер SoloTome.

Скачать расширениеОткрыть Amazon Docs

Установка

  1. Скачай ZIP и распакуй папку.
  2. Chrome → Расширения → Управление расширениями → включи «Режим разработчика».
  3. «Загрузить распакованное расширение» → выбери папку solotome-kindle-exporter.

Синхронизация

  1. Открой Amazon Content Library → Docs.
  2. Нажми SoloTome Kindle Exporter → «Собрать все книги».
  3. «Скопировать JSON».
  4. SoloTome → Настройки → Kindle → «Вставить из буфера» → «Проверить Kindle».
Независимый open-source helper. Amazon и Kindle являются товарными знаками Amazon. Расширение не аффилировано с Amazon.
